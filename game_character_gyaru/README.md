# Gyaru game character — import prototype

실제 Blender 3.6.7에서 제작한 스킨 메시 캐릭터 초안입니다. 생성 레퍼런스의 금발→분홍 헤어, 태닝 피부, 흰 민소매와 데님 반바지를 반영했습니다. 레퍼런스와 동일한 수준의 얼굴·헤어 디테일을 완성한 최종 아트 에셋은 아닙니다.

## 파일

- `gyaru_game_character.blend`: 편집 원본. 신체, 얼굴, 눈, 머리, 상의, 하의, 신발, 장식의 8개 메시와 뼈대.
- `exports/gyaru_game_character.glb`: Godot 등 glTF 호환 엔진에 가져갈 파일. 재질과 헤어 이미지, 스킨, 애니메이션 포함.
- `exports/gyaru_game_character.fbx`: Unreal 등에 가져갈 스켈레탈 메시. 커스텀 뼈대와 애니메이션 포함.
- `textures/hair_gradient.png`: 이식 가능한 헤어 그라데이션 텍스처. GLB 및 FBX에도 포함.
- `preview/`: 최종 정면·측면·후면·45도 렌더와 관절 테스트 렌더.
- `asset_report.json`: 내보내기 파일의 재가져오기 검사 결과.

## 사양

- 높이 약 1.60m, Z 위쪽 / -Y 정면, Blender 단위 1 = 1m.
- 약 4등신 스타일. 머리카락을 포함한 실루엣 때문에 정확한 두상 길이 비율은 다릅니다.
- 59,425 삼각형 / 30,230 정점 / 8개 메시 / 13개 재질.
- 42개 뼈대, 정점당 최대 4개 영향, 모든 정점의 웨이트 정규화.
- 전체 메시 UV 포함. 머리 이외에는 기본 Principled 재질의 색상과 거칠기 사용.
- `Idle`, `Rig_Check`: 각각 1~31프레임, 30fps. 기본 움직임 확인용 클립이며 완성된 걷기·달리기 애니메이션이 아닙니다.

## 엔진에 가져올 때

Godot에는 GLB를 프로젝트에 복사하여 사용합니다. Unreal에는 FBX를 새 스켈레탈 메시 및 새 Skeleton으로 가져오는 것을 기준으로 제작했습니다. 엔진에 가져온 뒤 크기와 정면 방향을 프로젝트 기준에 맞춰 확인하세요. 조작용 캐릭터 컨트롤러와 충돌체는 프로젝트에서 연결해야 합니다.

뼈대는 Unreal Manny/Quinn과 동일하지 않습니다. 기존 애니메이션을 사용하려면 뼈대 매핑과 리타기팅 작업이 필요합니다. 얼굴 표정용 블렌드셰이프, IK 제어 리그, 물리 에셋, 머리카락·의상 물리, LOD는 포함하지 않았습니다. 모바일 대상이면 재질 수와 폴리곤 예산을 더 줄이는 작업이 필요합니다.

## 확인한 내용과 한계

FBX와 GLB를 각각 비어 있는 Blender 장면에 다시 가져와 8개 스킨 메시, 뼈대 42개, UV 및 애니메이션 2개가 유지되는 것을 확인했습니다. 재가져오기 후 높이는 약 1.598m였습니다. 팔과 무릎을 굽힌 테스트 포즈를 렌더로 확인했습니다.

Unreal·Godot 실행 환경에서의 실제 런타임 검증은 수행하지 않았습니다. 관절 주변은 자동 생성한 삼각형 위주의 토폴로지이므로 극단적인 자세와 손가락 동작에는 수동 웨이트·토폴로지 보정이 필요할 수 있습니다. 얼굴 닮음, 웨이브 헤어, 의상 봉제선과 손 디테일은 초안 수준입니다.

## 제작 소스

`build_character.py` → `finalize_validate.py` → `polish.py` 순서로 제작했습니다. 각 스크립트는 해당 작업 폴더의 생성 결과를 다시 저장하므로, 수동 편집한 원본은 별도 이름으로 보관한 뒤 실행하세요. 기존 다른 Blender 연습 파일은 수정하지 않았습니다.
